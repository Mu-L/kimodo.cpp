# BONES-SEED training exemplars

These prompts are selected from NVIDIA's
[`SEED-Timeline-Annotations`](https://huggingface.co/datasets/nvidia/SEED-Timeline-Annotations)
only when their exact motion filename is present in the published
[`Kimodo-Motion-Gen-Benchmark`](https://huggingface.co/datasets/nvidia/Kimodo-Motion-Gen-Benchmark)
training split. `manifest.json` records the source split entry, event interval
and hashes of both downloaded source files.

The source datasets are published by NVIDIA under CC BY 4.0. The prompts are
included here as benchmark inputs with attribution to NVIDIA Corporation; no
claim is made that these annotations are original to `kimodo.cpp`.
